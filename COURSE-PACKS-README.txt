HOW TO IMPORT (admin)
---------------------
1. Sign in as admin.
2. Open Courses & modules.
3. Use the Import section / “Load from file”.
4. Select one JSON file at a time.
5. Leave “Make visible to learners now” UNTICKED until you have reviewed.
6. After import, use Show on modules/lessons when ready.
7. Matching public course cards (same title) already exist in the catalogue.
